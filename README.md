# 🌾 스마트팜 종합 농가 관리 시스템

스마트팜 농가의 효율적인 운영을 위한 **실시간 날씨 대시보드, 영농일지, 자료(문서) 관리, 일정/D-Day 관리** 통합 Streamlit 대시보드입니다. (IoT 센서 연동은 추후 확장 예정)

## 구성

| 페이지 | 내용 |
|---|---|
| 🏠 메인 대시보드 (`app.py`) | 실시간/가상 날씨, 강풍·폭우 안전 경고, 오늘의 핵심 요약(다가오는 일정·최근 일지·최근 자료) |
| 📝 영농일지 (`pages/1_영농일지.py`) | 작성일자·구역·작업유형·수확량·매출 기록, 검색/필터, CSV 다운로드 |
| 📁 자료 관리함 (`pages/2_자료관리함.py`) | 계약서·영수증·메뉴얼 등 파일 업로드, 카테고리 분류, 다운로드/삭제 |
| 📅 일정 관리 (`pages/3_일정관리.py`) | 일정 등록, 중요도·범주 설정, D-Day 정렬, 완료 체크 |

> 위 `pages/` 3개 파일은 순차적으로 추가되는 중입니다. 현재는 `app.py`(메인 대시보드)와 `db.py`(DB 모듈)까지 완성된 상태입니다.

데이터는 `data/smartfarm.db` (SQLite)에 저장되며, 앱 최초 실행 시 자동으로 테이블이 생성되고 샘플 데이터가 채워집니다. 업로드 파일 원본은 `data/uploads/`에 저장됩니다.

## 실시간 날씨 연동 (OpenWeatherMap API)

- API 키가 없어도 앱은 정상 작동하며, 자동으로 **가상(목업) 날씨 데이터**를 표시합니다.
- 무료 키 발급 방법(약 5분)은 앱 사이드바 **🔑 OpenWeatherMap API 키** 메뉴 안에 단계별로 안내되어 있습니다.
- 농장 위치는 사이드바에서 직접 좌표를 입력하거나, **📡 현재 위치로 자동 감지** 버튼으로 PC/모바일 브라우저의 GPS 위치를 바로 반영할 수 있습니다. (`streamlit-js-eval` 패키지 필요)

## 로컬 실행 방법

```bash
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 `http://localhost:8501` 로 접속합니다.

## 배포 (Streamlit Community Cloud 기준)

1. 이 저장소를 GitHub에 push
2. https://share.streamlit.io 접속 → New app
3. 저장소 선택, Main file path에 `app.py` 지정
4. Deploy

> 무료 플랜의 경우 파일 시스템이 재배포/재시작 시 초기화될 수 있어 `data/smartfarm.db`와 `data/uploads/`에 쌓인 데이터가 유실될 수 있습니다. 장기 운영 단계에서는 별도의 영구 DB(Postgres 등)나 클라우드 스토리지로 전환을 권장합니다.

## 데이터 관련 유의사항

- 계약서·영수증 등 업로드 자료에는 거래처 정보, 금액 등 민감한 내용이 포함될 수 있습니다. 저장소를 Public으로 운영할 경우 실제 파일은 `.gitignore`로 제외되어 GitHub에는 올라가지 않지만, 배포 환경의 접근 권한 관리에 유의해주세요.
- 재무/매출 관련 기록은 참고용 관리 대장이며, 실제 세무 신고·회계 처리는 세무사 확인을 권장합니다.
